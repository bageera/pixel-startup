# G31-A — Repository census + measured baseline (2026-11-21)

Environment: macOS 26.6.2 (arm64), backend running in Docker Desktop (image
`pixel-startup:latest`, built from source via `make start`), frontend served by the
backend at `http://127.0.0.1:19000`. Browser measurements: local Chrome (CDP), fresh
tab, ~2s idle observation. Command outputs are reproducible from the repository
checkout: `python3 tools/measure_office_baseline.py` (see below) + the test gate.

## Measured baseline (fresh Chrome tab, office at :19000)

| Metric | Value | Note |
| --- | --- | --- |
| Scene init (DOMContentLoaded→interactive) | ~1.2–1.5s observed via `performance.now()` snapshots | splash path |
| Idle rAF rate (pre-login scene) | **32 frames / 2s ≈ 16 fps** | the loop redraws the full scene every frame even when nothing changes — G32-B target #1 (idle = 0 incremental work) |
| JS heap (idle splash) | 13.2 MB | bounded by scene, fine |
| Network to load office | 23 requests / ~56 KB | sprite sheets load lazily during draw |
| Animated canvases | 1 (640×800) | no WebGL anywhere |
| Persistent intervals | 5 | poll/presence; unscaled with org size |
| `GET /api/v1/graph` latency (live, empty graph) | ~21–55 ms (first call 310ms incl. cold import) | projection is a single O(n) pass |
| `GET /api/v1/graph/impact` | live 200 `{blockers:[],risks:[],unblocked:[]}` | route migrated and exercised |
| Python API healthz | 12 ms | |
| Test suites | 175 pytest / 65 npm / pyright 0 / ruff clean | at commit of Phase 1 |

Measured limits of this pass (honest skips): frame-time percentiles and dropped-frame
counts need a sustained interaction session (Phase 3 will re-measure with the
instrumented loop); "idle CPU %" is currently inferred from the 16 fps idle rAF
evidence (full redraw per frame) rather than a profiler number.

## Dependency of Phase 2+ on this baseline

G32-B targets from evidence: idle rAF full-redraw → dirty-layer/idle-stop;
5 interval polls → scoped/etag'd; renderer is already 2d-canvas — no WebGL2 need
until the stress gauntlet says otherwise (see docs/g32-resource-discipline.md).
